# Finance Monitoring. 

![Project Image](https://t3.ftcdn.net/jpg/07/33/18/84/360_F_733188494_Z4l5dioGj1xPTmHKCN9a26R9mLify3hP.jpg)

I developed a small application allowing myself to monitor the evolution of stock markets prices for popular Tech companies, by requesting the Marketstack API.

---

## ⚙️ Technologies

**Python**: 
- requests for API calls
- polars to convert JSON data to a dataframe
- pandas for data processing
- matplotlib/seaborn for data vizualization

--> You can check *documentation/Interview_Questions.md* for more information.

## 🔍 Objective 

- **Get daily update about stock market prices for a selection of companies**
- **Gather all the information in a centralized application**
- **Use AI to analyze trends and give recommendations based on it**

## 💽 Raw Data

**Marketstack API**
https://marketstack.com/
